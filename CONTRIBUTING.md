# Contribuer à Nala / Contributing to Nala

Merci de l'intérêt porté à Nala ! / Thank you for your interest in Nala!

## 🐛 Signaler un bug / Report a bug
Si vous trouvez un bug, merci d'ouvrir une "Issue" en décrivant :
- Les étapes pour reproduire le bug.
- Le comportement attendu.
- Votre version de Windows et la version de Nala.

If you find a bug, please open an Issue describing:
- Steps to reproduce.
- Expected behavior.
- Your Windows version and Nala version.

## 💡 Proposer une idée / Feature request
Vous avez une idée d'amélioration ? Ouvrez une "Issue" en expliquant votre besoin.
Have an idea? Open an Issue explaining your need.

## 💻 Contribuer au code / Code contribution
1. Forkez le projet.
2. Créez une branche (`git checkout -b feature/ma-super-idee`).
3. Faites vos modifications.
4. Testez votre code.
5. Soumettez une "Pull Request".

1. Fork the project.
2. Create a branch (`git checkout -b feature/my-great-idea`).
3. Make your changes.
4. Test your code.
5. Submit a Pull Request.

## 📝 Style de code / Code style
Merci de garder le code commenté et de suivre le style existant.
Please keep the code commented and follow the existing style.
